# Zia Yousaf — Portfolio

A React portfolio for selected product, platform and web work. The visual identity keeps the original dusk-sky and campfire palette while presenting the projects as case studies.

## Run locally

This project uses Node.js 20 LTS. With `nvm` installed, open a terminal in this folder and run:

```sh
nvm install
nvm use
npm install
npm start
```

The `.nvmrc` file selects Node 20 automatically when you run `nvm use` from the project folder.

Create a production build with `npm run build`. This is a client-routed React app; configure static hosting to serve `index.html` for page routes.
